## 5. Potential Challenges & Mitigation

| Risk | Impact | Likelihood | Mitigation Strategy |
|------|--------|------------|---------------------|
| **Missing dress photography** | High | Medium | Use professional placeholder images temporarily; schedule photoshoot |
| **Slow page load on mobile** | High | Low | Implement image optimization, lazy loading, and CDN caching |
| **Low WhatsApp response rate** | Medium | Medium | Set up auto-reply message with business hours |
| **Arabic language support** | Medium | High | Start with English, add Arabic as Phase 2 enhancement |
| **Instagram API limitations** | Low | Medium | Use static gallery with manual updates vs. live feed |
| **Domain availability** | Medium | Low | Reserve multiple domain options early |
